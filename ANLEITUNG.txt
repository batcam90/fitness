FORMKURS 2 – Update für GitHub Pages

1. Die ZIP-Datei auf dem Mac entpacken.
2. In GitHub dein bereits vorhandenes Repository „formkurs“ öffnen.
3. Add file -> Upload files wählen.
4. Die entpackten Dateien direkt ins Hauptverzeichnis hochladen (nicht die ZIP-Datei).
   Bereits vorhandene Dateien index.html, sw.js, manifest.webmanifest und Icons werden ersetzt.
5. Unten Commit changes anklicken. Die Pages-Einstellungen bleiben bestehen.
6. Auf dem iPhone FORMKURS in Safari aufrufen und neu laden. Falls noch die alte Version erscheint:
   Web-App vollständig schließen und nochmals starten oder Safari-Seite neu laden.

WICHTIG: Nutze dasselbe GitHub-Repository und dieselbe Adresse.
Die bestehende lokale Speicherung mit dem Schlüssel formkurs_app_v1 bleibt erhalten.
Deine bisherigen Gewichts- und Übungseinträge sollen dadurch nicht überschrieben werden.
Trotzdem vorher in FORMKURS unter „Fortschritt“ -> „Backup exportieren“ eine Sicherung erstellen.

25 zusätzliche schnelle Rezepte, eigene Rezepte mit Fotos und JSON-Backup inkl. Rezeptfotos.

lokalen Browserspeicher füllen. Nutze regelmäßig „Backup exportieren“.
